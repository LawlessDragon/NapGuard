# 😴 NapGuard

Sistem deteksi kantuk real-time menggunakan teknologi computer vision untuk meningkatkan keselamatan berkendara.

## 🎯 Tujuan

NapGuard dirancang untuk mendeteksi tanda-tanda kantuk/kelelahan pengemudi secara real-time dan memberikan peringatan untuk mencegah kecelakaan.

## ✨ Fitur

- 👁️ Real-time face detection
- 😴 Drowsiness detection
- 🔔 Alert notifications
- 📊 Activity tracking
- 📱 Web-based interface

## 🛠️ Tech Stack

- **Frontend:** HTML/CSS/JavaScript
- **ML:** TensorFlow.js / MediaPipe
- **Deployment:** Vercel

## 🚀 Getting Started

1. Clone repository
   ```bash
   git clone https://github.com/LawlessDragon/NapGuard.git
   ```

2. Open `index.html` di browser

3. Allow camera access

## 📖 Cara Kerja

1. Aplikasi mengakses webcam perangkat
2. Mendeteksi posisi mata dan wajah
3. Menganalisis pola sleeping/blinking
4. Memberikan peringatan jika terdeteksi kantuk

## ⚠️ Disclaimer

NapGuard adalah bantuan tambahan. Selalu prioritaskan keselamatan berkendara yang bertanggung jawab.
